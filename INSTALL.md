# Установка — свой бот за 10-15 минут

Бот работает только у вас — свой токен, свой сервер (хоть обычный ПК, который
не выключаете), свои данные, никто чужой их не видит. Устанавливает и
администрирует бота любой, без программирования.

## Что нужно

- Любой компьютер с Linux или macOS, который может быть включён (постоянно —
  если хотите, чтобы бот отвечал всегда; достаточно и обычного домашнего ПК).
- Python 3.10 или новее.
- Аккаунт в Telegram.

## 1. Получите токен бота

В Telegram напишите **@BotFather** → `/newbot` → придумайте имя и username.
В ответ пришлёт токен вида `123456:AAG...` — он понадобится дальше.

## 2. Получите бесплатный ключ Gemini

Бот распознаёт траты по тексту/голосу/фото через Gemini. Ключ бесплатный:
https://aistudio.google.com/app/apikey → "Create API key".

## 3. Скачайте и настройте

```bash
git clone https://github.com/Aleksandr-Kai/family-budget-bot.git
cd family-budget-bot
./setup.sh
```

Скрипт спросит токен бота и ключ Gemini, создаст `.env` и виртуальное
окружение. `ADMIN_CHAT_ID` оставьте пустым — так и задумано (см. ниже).

## 4. Запустите и станьте администратором

```bash
.venv/bin/python3 bot.py
```

Откройте вашего бота в Telegram и отправьте `/start`. **Первый, кто это
сделает, автоматически становится администратором** — отдельно прописывать
свой chat_id в `.env` не нужно.

## 5. Позовите семью

Команда `/invite` пришлёт ссылку вида `t.me/ваш_бот?start=inv_XXXXX`.
Перешедший по ней сразу получает доступ — без вашего ручного подтверждения
на каждого. Если ссылка потерялась или нужно отозвать доступ для новых людей
по старой ссылке — `/invite new` выпустит новую (старая перестанет работать).

Если кто-то напишет боту без ссылки — бот предложит отправить `/join`,
заявка придёт вам, и вы одобрите её командой `/pending` или кнопками под
уведомлением.

## Автозапуск (чтобы бот работал постоянно)

Проще всего — через `systemd --user` (не нужен root/sudo):

```bash
mkdir -p ~/.config/systemd/user
cat > ~/.config/systemd/user/money-control-bot.service <<EOF
[Unit]
Description=Family budget bot

[Service]
WorkingDirectory=$(pwd)
ExecStart=$(pwd)/.venv/bin/python3 $(pwd)/bot.py
Restart=on-failure

[Install]
WantedBy=default.target
EOF

systemctl --user daemon-reload
systemctl --user enable --now money-control-bot
loginctl enable-linger "$USER"   # чтобы бот стартовал и без входа в систему
```

Проверка: `systemctl --user status money-control-bot`.

## Мини-приложение (опционально)

`webapp_server.py` — экран в Telegram со сводками, бюджетами и списком
покупок (кнопка рядом с полем ввода сообщения). Все зависимости уже
установлены скриптом `setup.sh`, достаточно запустить:

```bash
.venv/bin/python3 webapp_server.py        # слушает 127.0.0.1:8793
```

Боту нужен публичный HTTPS-адрес для него — проще всего через Cloudflare
quick tunnel (бесплатно, без домена и регистрации):

```bash
cloudflared tunnel --url http://127.0.0.1:8793
```

Выданный адрес (`https://....trycloudflare.com`) впишите в `.env` как
`EXPERIMENTAL_MINIAPP_URL` и перезапустите бота. У quick-туннеля адрес
меняется при каждом перезапуске — для постоянной работы оформите оба
процесса сервисами systemd по аналогии с разделом выше.

## Что хранится и где

Все данные — в одном файле `money_control.db` рядом с `bot.py`. Ничего не
уходит никуда, кроме: сообщений в Telegram (чтобы отвечать) и запросов к
Gemini/DeepSeek (чтобы распознать текст/голос/фото траты — сам текст уходит
туда, фото/суммы в открытом виде третьим лицам не передаются и нигде не
хранятся, кроме вашей базы).
